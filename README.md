基于 STM32F103C8T6 的双闭环 PID 自主循迹小车，支持多种轨迹模式一键切换。

---

## 项目简介

一辆能自主识别并跟踪地面黑色轨迹线的智能小车。通过 5 路红外传感器阵列感知轨迹位置，驱动两个直流电机实现精准的路径跟随。

## 项目亮点

### 串级双闭环 PID 控制

外环循迹 PD（20 ms）根据传感器偏差输出左右轮速差量，内环速度 PI（5 ms）根据编码器反馈精确控制电机转速。两级闭环协同，兼顾轨迹跟踪精度与速度响应，在急弯和直线场景下均表现稳定。

```
IR传感器 → 外环 PD (位置) → 速度设定 → 内环 PI (速度) → PWM → 电机
                ↑                                      │
                └──────── 编码器反馈 ──────────────────┘
```

### 有限状态机模式系统

将复杂的循迹行为抽象为独立的状态机，每个模式（三角形 / 圆形 / 弯道自适应 / 路径序列）内部通过清晰的状态转移实现闭环自治。通过单个按键（PA5）即可切换模式，模块间零耦合。

### 增量式速度 PI + 抗饱和

内环采用增量式 PI 算法，配合低通滤波器平滑编码器读数，加上积分限幅与输出 PWM 饱和回退，有效避免长时间偏差导致的积分饱和失控。

## 已完成模式

| 模式 | 状态机 | 核心机制 |
|------|--------|---------|
| **三角形循迹** | 6 状态 FSM | RIGHT2 检测黑线触发两阶段左转，丢线方向记忆恢复 |
| **圆形循迹** | 4 状态 FSM | RIGHT2 边沿计数（3 次白→黑）自动停车，丢线原地旋转搜索 |

## 技术栈

- **MCU**: STM32F103C8T6 (Cortex-M3, 72 MHz)
- **传感器**: 5 路红外反射式阵列
- **电机驱动**: TB6621FNG 双路 H 桥 + 正交编码器
- **开发工具**: STM32CubeMX + Keil MDK-ARM (HAL 库)
- **通信**: USART1 调试输出 (115200 8N1)

## 构建 & 运行

1. 用 Keil MDK 打开 `MDK-ARM/STM32-AutoTrace-Car.uvprojx`
2. 编译并烧录到 STM32F103C8T6
3. 上电后按 PA5 按键切换模式
